### **3. Directory and File Details**
Provide detailed descriptions of each directory and file type, including purpose, format, and usage.

#### **A. [Directory 1: Cutouts]**
Contains cropped plant images, masks, and associated metadata.

| **File Type**   | **Format** | **Description**                                          | **Example Filename**           |
|-----------------|-----------|----------------------------------------------------------|-------------------------------|
| Metadata        | `.json`   | Plant-specific information, including bounding boxes, class, and environmental metadata. | `plant_12345.json`             |
| Cutout Mask     | `.png`    | Binary mask generated by the segmentation model.          | `plant_12345_mask.png`         |
| Cropout Image   | `.jpg`    | Cropped image of the targeted plant, based on bounding box coordinates. | `plant_12345.jpg`              |
| Cutout Image    | `.png`    | Final processed image with transparent background.        | `plant_12345_cutout.png`       |

#### **B. [Directory 2: Developed Images]**
Contains full-size pre-processed images and associated processing profiles.

| **File Type**   | **Format** | **Description**                                          | **Example Filename**           |
|-----------------|-----------|----------------------------------------------------------|-------------------------------|
| Pre-Processed Image | `.jpg` | Full-size image after color correction, sharpening, and exposure adjustment. | `IMG_20240101_123456.jpg`      |
| Processing Profile | `.pp3`  | RawTherapee sidecar file with applied image adjustments.  | `IMG_20240101_123456.jpg.pp3`  |
